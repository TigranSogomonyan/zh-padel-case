# ZH — кейс для портфолио

> Источник: код и документы проекта (`files/HANDOFF.md`, `.site/README.md`, `api/README.md`). Папка **не является git-репозиторием**, истории коммитов нет — пункты, которые зависят от неё, помечены «спросить Тиграна».

## 1. Название и одна строка
**ZH — Padel Racket Case.** Сайт-конфигуратор кожаного чехла для падел-ракетки: выбираешь цвет кожи, ставишь свои инициалы блинтовым тиснением, смотришь вещь в 3D и отправляешь заявку.

## 2. Для кого и задача
- Аудитория: игроки в падел, которым нужен именной чехол ручной работы «на заказ» (интерфейс на английском, бренд ZH).
- Задача: дать посмотреть настроенную вещь до заказа и получить заявку со всеми параметрами в миллиметрах.
- Клиент / заказчик, бизнес-цель, реальный владелец бренда — **спросить Тиграна** (из кода не видно, свой ли это бренд или заказ).

## 4. Стек и ключевые решения
- **Фронтенд:** один самодостаточный `index.html`, без сборщиков; three.js r128 лежит в `vendor/`.
- **Рендер:** по умолчанию собственный программный растеризатор на canvas 2D (`makeSoft()`), WebGL включается только `?gl=1`. Причина: на рабочей машине WebGL не поднимается ни в одном браузере.
- **Бэкенд:** Laravel (`api/`): принимает заявку, кладёт в базу вместе с превью, шлёт в Telegram-канал ботом; если бот молчит, заявка всё равно сохранена (`post_error`). 11 тестов.
- **Сервер:** `server.js` на node без зависимостей, проксирует `/api/*` в Laravel — форма работает одинаково локально и через туннель.
- **Выкладка:** `npm run deploy` собирает standalone-файл (three.js и шрифты вшиты) и отправляет в GitHub Pages.
- **Проверки:** прогоны страницы в node с заглушками DOM (`page-run`, `scene-check`), включая режимы без WebGL.

## 5. Фишки, которыми можно гордиться
1. **3D без видеокарты.** Свой растеризатор: два прохода (быстрый при вращении ~19 мс, чистовой в покое ~50 мс), билинейные текстуры с пирамидой уменьшений, рельеф кожи по карте нормалей.
2. **Кожа из рельефа.** Из снятой текстуры Leather037 берётся только карта высот, а albedo, нормали, блеск и затенение борозд считаются в браузере; цвет задаёт палитра. Процедурный флотар (плитка 55 мм, чешуйка 2,2 мм) остался запасным вариантом.
3. **Блинтовый оттиск инициалов:** до трёх знаков, латиница и кириллица, три шрифта, 14–60 мм, перетаскивается мышью и идёт по кривизне поверхности (аналитическая посадка `zAt`/`project`).
4. **Силуэт по меркам:** полуширина как функция длины, сплайн `pchip`, развёртка без шва — 84,6% площади в пределах 5% от точного масштаба зерна, периметр ровно 23 плитки.
5. **Заявка не теряется:** страница работает без WebGL, форма не зависит от 3D, Telegram может молчать — заявка в базе. Плюс история пойманного бага: в треугольнике поле `bx` затирало вершину B — по числам геометрия была идеальна, нашли только по картинке (чистовой кадр 834 мс вместо 44).

## 6. Что отбросили и почему
Из HANDOFF (git-истории нет):
- Жёсткая скорлупа → мягкий чехол (по образцу).
- Молния → два кожаных хлястика с D-кольцами на спинке (по образцу).
- Гладкая кожа и сафьяно → оставлен флотар; затем процедурный флотар заменён снятой картой рельефа Leather037 (ambientCG, CC0, 28.10.2026). Процедурные выделки сохранены в коде за `?leather=…`, в панели их нет.
- WebGL как основной путь → программный рендер (WebGL не поднимается).
- Не сделано: нейлоновое переплетение ремня, собственные тени (ремень на корпусе), сверка силуэта с образцом. Падающая тень на подложку добавлена 28.10.2026.
- Остальные отброшенные варианты по ходу работы — **спросить Тиграна**.
