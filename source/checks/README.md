# Проверки

Обе гоняют сам `index.html`, а не его копию: скрипты страницы выполняются
в node с настоящим three, с заглушками DOM, канвы и рендерера.

```
npm i
node checks/page-run.js      # страница вхолостую: сборка, панель, форма заказа
NOGL=1 node checks/page-run.js    # без WebGL — рисует программный рендер
GLBLANK=1 node checks/page-run.js # контекст есть, кадр пустой — переключается сама
node checks/scene-check.js   # обмеры собранной сцены: габарит, кант, ремень,
                             # развёртка кожи, проекция оттиска против рейкаста
node checks/render.js out.png navy    # три вида в PNG отдельным рендером
node checks/render-soft.js out.png   # кадр, который рисует сама страница без WebGL
node checks/bench-soft.js            # сколько стоит кадр программного рендера
```

`render.js` — свой растеризатор с z-буфером и ламбертовым светом, без
зависимостей. Текстур кожи в нём нет, площадка оттиска просто затемнена:
задача — увидеть форму, силуэт и посадку фурнитуры. Цвет: navy, aqua,
burgundy, orange, brown, white.

`harness.js` — общие заглушки; путь к `index.html` берётся относительно `checks/`. Переменная `INDEX` позволяет проверить другую сборку.
