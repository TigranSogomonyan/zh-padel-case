# ZH — первый этап, 03.11.2026

Исходники найдены в оригинальной папке ZH: `index.html` (HTML, CSS, JS, сцена и Canvas 2D), `checks/`, `server.js`, `vendor/`, `textures/`, а также Laravel в `api/`. Прочитаны `files/HANDOFF.md`, `checks/README.md`, `api/README.md`, аудит и handoff PR №1. Локальная папка не была Git-репозиторием.

## Исходник и публикация

В `source/` сохранён редактируемый frontend и существующие проверки. Первый коммит переносит исходный frontend, второй содержит исправления — для ревью удобно смотреть второй коммит. Корневой публикационный `index.html` не изменён. Сборка для ревью создаёт игнорируемый `artifacts-stage1.html`, не публикует сайт. Команда автоматического деплоя в `main` в копию исходников не перенесена.

Laravel остаётся в оригинальной локальной папке `ZH/api/`: его код, `.env`, база, журнал и пользовательские превью в этот PR не копируются. Backend не менялся. Для локальной работы frontend `server.js` проксирует `/api/*` в `ZH_API` (по умолчанию `http://127.0.0.1:8000`). Laravel запускается отдельно в оригинальной папке: `php artisan serve`.

```sh
npm ci
npm ci --prefix source
npm --prefix source start       # http://localhost:5310
npm --prefix source run check
npm run build:stage1            # только локальная review-сборка
npx playwright install chromium
npm run test:stage1
```

Для установленного Chrome можно задать `CHROME_PATH` — локальные проверки выполнены в headless Google Chrome на macOS. CI использует Chromium Playwright.

## Изменения

- Цвета: отдельная зона 44×44 px, видимый круг 42 / 39 / 30 px на 390 / 375 / 320 px. На 375 и 320 px — два ряда по три. Hover не увеличивает область кнопки. Соседние зоны не пересекаются.
- Четыре ракурса на мобильных имеют ширину и высоту не меньше 44 px. Кнопки ремня и шрифта также имеют высоту от 44 px.
- Across и Along связаны с ползунками через `label[for]`. Шрифты получают разные доступные названия. Усилен фокус, убраны подавлявшие его правила полей.
- Кнопка Continue to request в конце мобильной панели переводит к заявке и переносит фокус на заголовок.
- Статическая версия сразу показывает Copy configuration и объясняет, что отправки нет. Копирование не требует имени или email. Контакт для отправки не выдуман: если контакта ZH ещё нет, предлагается сохранить спецификацию.
- При отказе API поля сохраняются, автоматического копирования нет; предлагается явное копирование. Отказ буфера получает отдельное сообщение. Успех отправки требует JSON `{ok:true, ref:...}`, совпадающий с контрактом `OrderController`. При неопределённом исходе пользователь должен уточнить результат у ZH до повторной отправки.
- Canvas 2D, геометрия, шесть цветов, тиснение, ремень, камеры и сохранение PNG сохранены. Цена и сроки не добавлялись.

## Проверки

Существующий `npm run check` проходит: разметка, интерфейс, software по умолчанию, отсутствие WebGL, пустой WebGL и геометрия/проекция оттиска.

Расширен существующий `tests/smoke.mjs` из PR №1, без отдельного дублирующего responsive suite. Проверены 1440×900, 390×844, 375×844 и 320×844:

- один Canvas, ноль необработанных ошибок JavaScript и ноль пикселей горизонтального переполнения;
- изображение Canvas меняется после Burgundy, ZH и Back;
- нет безымянных полей и кнопок;
- мобильные зоны кожи и камеры ≥44×44 px, не пересекаются;
- ползунки управляются стрелками и имеют видимый фокус; цвет выбирается Enter;
- мобильный переход к заявке переносит фокус;
- Save preview скачивает непустой PNG с корректной сигнатурой;
- Copy configuration реально помещает выбранную спецификацию в буфер.

`tests/order-fallback.mjs` проверяет на изолированном HTTP-сервере: 502, 200 без подтверждения, 201 с `{ok:true,ref}` и блокировку буфера обмена. Реальные заказы не создавались. Подробности: [browser report](stage1-browser-report.json), [order report](stage1-order-report.json).

PHP-тесты запущены в оригинальном `api/`, но не завершились из-за выгруженных в iCloud зависимостей `vendor/`; результат не заявляется как успешный. Production API и реальные мобильные устройства не проверялись.
